Hardware Wrappers

Control any motor with a single, unified API. Support for voltage compensation, current limiting, and PID is built-in.

import ca.team4308.absolutelib.wrapper.MotorWrapper;
import ca.team4308.absolutelib.wrapper.MotorWrapper.MotorType;

// Initialize different motors with strict typing
MotorWrapper falcon = new MotorWrapper(MotorType.TALONFX, 10);
MotorWrapper neo = new MotorWrapper(MotorType.SPARKMAX, 11);

// Unified control
falcon.setVoltage(12.0);
neo.setVoltage(6.0);
