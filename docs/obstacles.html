Obstacle Avoidance

Define field obstacles like the Hub to automatically route shots over them.

ObstacleConfig hub = ObstacleConfig.builder()
    .position(4.03, 4.0)
    .baseSize(1.19)
    .wallHeight(1.83)
    .build();

ShotInput input = ShotInput.builder()
    .addObstacle(hub)
    .collisionCheckEnabled(true)
    .build();
