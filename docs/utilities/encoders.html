Encoder Wrappers

Vendor-agnostic interface for position tracking.

Concept

EncoderWrapper abstracts away the differences between CTRE CANCoders, Rev ThroughBore Encoders (DIO), and integrated motor encoders. It provides a standard API for reading position in Mechanism Rotations, Radians, or Meters.

Factories

// CTRE CANCoder
EncoderWrapper swerveEnc = EncoderWrapper.canCoder(10, 1.0);

// Integrated Falcon/Kraken (with gear ratio)
EncoderWrapper elevatorEnc = EncoderWrapper.talonFXIntegrated(15, 12.5, 2.0); // ID 15, 12.5:1 ratio, 2" drum

// DIO Encoder (Rev ThroughBore)
EncoderWrapper wristEnc = EncoderWrapper.dioEncoder(0, 1, false, 4.0, 8192, 0.0);

Usage

// Get position in mechanism rotations (post-gearing)
double rots = elevatorEnc.getPositionMechanismRotations();

// Get position in meters (if drum diameter was provided)
double height = elevatorEnc.getPositionMeters();

// Simulation Support
elevatorEnc.setSimulatedPositionMechanismRotations(10.5);
