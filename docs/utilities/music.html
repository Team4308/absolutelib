Music Player

Turn your robot into an orchestra with TalonFX/Falcon 500s.

Usage

Wraps the CTRE Orchestra class to simplify loading and playing .chrp music files. It only works with TalonFX or Kraken motors.

// Initialize
Orchestra orchestra = new Orchestra();
musicPlayer player = new musicPlayer(orchestra);

// Add Instruments (Motors)
player.addInstruments(new MotorWrapper[] { 
    drive.leftMaster, drive.rightMaster, shooter.flywheel 
});

// Load and Play
player.loadSong("tuning_song.chrp");
player.playSong();
